## 关键状态约定

即时确认也必须收到供应方明确确认后才进入确认结果；异步确认先保持 `PENDING_CONFIRM`。网络失败和未查明状态保持 `UNKNOWN` 并查证，确认期限届满不等于供应失败，不擅自释放可能已经履约的配额。

付款时机由渠道政策 `BEFORE_SUBMIT` 或 `AFTER_CONFIRM` 显式决定。只有资金成功和供应确认都满足时才完成确认。取消请求、供应取消结果和退款结果分别保存；退款失败、取消未知均不能伪装成完成。已确认库存只能凭独立取消凭据和所属订单确认取消后归还。

实际应用端口：gateway8080、auth8081、user8082、hotel8083、inventory8084、order8085、admin8087、ai8088、supplier8089、channel8090。8086 已退役。配置测试同时核对常量、AGENTS、Prometheus 与各服务实际 `application.yml`。

渠道请求使用原始请求体 SHA256，再对“渠道编码、时间戳、随机 nonce、HTTP 方法、外部路径及查询串、摘要”的换行连接值做 HMAC-SHA256。随机 nonce 持久化防重放；签名路径包含 `/api/channel/booking`。供应回调和资金事件采用独立签名协议，详见 [交易接口契约](交易接口契约.md)。平台 JWT 不能替代渠道 HMAC。

## 启动与跨 HTTP 验收

基础设施按本项目现有 Nacos/MySQL/Redis/Kafka 配置启动。专用测试库已重建、服务连接信息正确后，在各终端加载同一环境文件，再运行服务。Java 服务在同一台本机运行，使测试通知可回到 `127.0.0.1:18091`；若运行在容器或远端，必须明确调整可达回调地址及测试安全配置，不能照抄 loopback。

每条 Maven 命令最多三个模块，不使用 `-am` 隐含扩大构建范围。先安装父 POM/common，再分批构建：

```bash
mvn -N install -DskipTests
mvn -pl ota-common install -DskipTests
mvn -pl ota-gateway,ota-inventory,ota-order package -DskipTests
mvn -pl ota-supplier,ota-channel package -DskipTests
```

分别在加载环境文件的终端执行 `java -jar ota-模块/target/ota-模块-1.0.0-SNAPSHOT.jar`，实际文件名以 target 构建产物为准。启动 gateway、inventory、order、supplier、channel；必要基础设施和所有依赖服务必须可达。功能开关及 TEST 密钥由脚本生成。旧订单和旧上下游任务默认关闭。

```bash
source /tmp/ota-booking-test.env
python3 scripts/booking-flow-smoke.py
```

smoke 使用标准库发起真实 HTTP，不替换 Java 业务实现：经 Gateway 签名报价、建单、同外部订单号重试与 409 内容冲突；即时确认及异步待确认；异步供应签名回调与重复回调；TEST 支付；取消退款；显式 `REJECT_CANCEL` 拒绝取消后保持预订/配额/资金并拒绝换号重试；显式 `UNKNOWN` 提交未知后保持配额并按原请求号查证恢复；建单前预注册 `WRONG_ACK` 观察付款前旧版本错误 ACK 后被付款后新版本标为 `SUPERSEDED`（绝不将 `SUPERSEDED` 当作送达成功），并绑定付款后稳定目标版本证明错误 ACK 不标 `DELIVERED`、恢复正确 ACK 后重投送达；建单前预注册 `ALWAYS_WRONG_ACK` 绑定付款后稳定目标版本验证有界重试耗尽进入 `DEAD` 死信、未授权重放返回 `403`、授权人工重放写入 `operator`/`reason` 审计并送达；验证正常订单及故障恢复订单的稳定版本全部收到最终签名通知并返回事件 ACK。对 `127.0.0.1`/`localhost` 回环地址默认直连（不经系统 HTTP 代理），不修改用户全局代理设置。它本地启动临时回调接收器，结束后关闭；输出订单 ID、模式与验收结果，不输出密钥。可用 `--gateway`、`--order`、`--supplier`、`--channel`、`--callback-port`、`--timeout` 调整地址及等待时间，也可用 `--verify-negatives` 执行本地正向基线与 `反测-01a/01b/02/03` 反向自测。重建时 callback URL 与实际接收器必须一致。
